# IW WordPress Extensions

Colección de extensiones de IngeWeb para WordPress. Cada plugin se organiza bajo `plugins/`, con código fuente y documentación propia; los ZIP recibidos se conservan en `dist/`.

## Plugins

| Plugin | Función | Versión declarada | Estado |
| --- | --- | --- | --- |
| [IW Search Results](plugins/iw-search-results) | Resultados de búsqueda global, catálogo visual, búsqueda exclusiva de productos WooCommerce y búsqueda exclusiva de posts, con filtros por categorías, exclusiones por ID e integración opcional de características de IW Product Features. | 1.4.2 | En uso y evolución |
| [Indicadores Económicos de Colombia](plugins/indicadores-economicos-colombia) | Muestra TRM, inflación mensual, tasa de intervención y UVR mediante `[indicadores_colombia]`. | 1.0.1 | Requiere revisión y pruebas |
| [IW WhatsApp Button](plugins/wc-whatsapp-button) | Botón flotante para WordPress y compra por WhatsApp con precio, cantidad y variaciones en WooCommerce opcional. | 1.2.0 | Sintaxis y ZIP verificados; pendiente validación en sitio |

| [IW Product Coverage](plugins/iw-product-coverage) | Cobertura regional por producto WooCommerce, contenido condicional en Divi y región seleccionada en Contact Form 7. | 1.0.0 | Sintaxis y selector verificados; pendiente validación en sitio |

| [IW MegaMenu Divi](plugins/iw-megamenu-divi) | Mega menús por columnas o enlaces con Divi Library. Implementado para Maicito. | 1.0.0 | Implementado en Maicito; pendiente verificar apariencia y funcionamiento en Divi estándar |

## Compatibilidad y revisión

Los ZIP incluyen los paquetes instalables de cada extensión. Revisa la documentación de cada plugin antes de usar o distribuir.

Las versiones compatibles de WordPress, PHP y WooCommerce, así como las licencias, deben confirmarse para cada extensión. La presencia de un plugin en este repositorio no constituye una certificación de compatibilidad o seguridad.
